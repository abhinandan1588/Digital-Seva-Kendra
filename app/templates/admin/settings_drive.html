First-time Google Cloud setup (one time)
  1. Create a project at console.cloud.google.com and enable the Google Drive API.
  2. OAuth consent screen: External, add your shop's Google account as test user; scope .../auth/drive.
  3. Credentials → OAuth client ID → Web application. Add authorized redirect URI: {{ url_for('admin.drive_callback', _external=True) }}
  4. Download the client secret JSON, save it on the server and set GOOGLE_CLIENT_SECRETS_FILE in the .env file.
  5. Restart the app, then press Connect Google Drive above and sign in with the shop's Google account.
Tokens are stored encrypted server-side and never exposed to the browser. Full guide: docs/GOOGLE_DRIVE_SETUP.md
